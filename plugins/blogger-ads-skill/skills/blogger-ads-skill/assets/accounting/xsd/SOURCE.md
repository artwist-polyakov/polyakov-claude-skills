# Источник схемы ФНС

- Приказ ФНС от 19.12.2023 № ЕД-7-26/970@, приложение № 1, версия формата 5.03.
- [Официальная страница приказа](https://www.nalog.gov.ru/rn77/about_fts/docs/14414412/).
- [Архив «xsd-схема, действующая с 01.01.2026»](https://www.nalog.gov.ru/html/sites/www.new.nalog.ru/files/about_fts/docs/xsd/14414412.zip).
- Получена и проверена 17.10.2026. В архиве один файл: `ON_NSCHFDOPPR_1_997_01_05_03_05.xsd`.
- Размер: 194743 байта. SHA-256: `9bd06a0c6eaffd33e011efc0a7bf96346bcbf14ea1da9b88049c96a30f1b8221`.
- Байты, перевод строк и кодировка Windows-1251 сохранены без изменений. Это официальный нормативный формат, не схема, выдуманная под генератор.

`lxml.etree.XMLSchema` проверяет структуру и типы XSD. Схема также содержит правила Schematron с расширениями ФНС; lxml.XMLSchema **не исполняет эти правила**. Для поддерживаемого узкого профиля основные условия проверяет `accounting.py`, однако проверка XSD не заменяет проверки оператора, полномочий, электронной подписи, арифметических и налоговых условий сделки.

При обновлении схемы: получить файл с сайта ФНС, обновить имя и контрольную сумму здесь и `SCHEMA` в скрипте, прогнать тесты обоих функций ДОП/СЧФДОП и импорт через выбранного оператора. Не редактировать XSD, чтобы «починить» неподходящий XML.
