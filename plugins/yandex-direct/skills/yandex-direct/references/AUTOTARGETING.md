# Автотаргетинг: узкий старт и расширение охвата

Читайте этот справочник при создании поисковой рекламы, выборе категорий
автотаргетинга, проверке нецелевых запросов или поиске дополнительного трафика.
Пользователь может не знать о категориях: объясните их влияние сами.

## С чего начинать

Для новой поисковой группы по умолчанию предлагайте **только узкие запросы**:
`Narrow=YES`, остальные четыре категории — `NO`. Включите этот выбор в план
создания. Это осторожный стартовый подход скилла, а не требование Яндекса
или гарантия качественного трафика. Если пользователь уже выбрал другой
состав, используйте его. Работающую рекламу не переводите на узкие запросы
автоматически: сначала оцените, какие полезные обращения могут исчезнуть.

Категории запросов применяются на Поиске и в Картах. В РСЯ автотаргетинг работает по другой
механике; эти переключатели не ограничивают сетевые показы до «узкой» аудитории.
Для товарной галереи Яндекс рекомендует включать все категории: при выборе
только узких объясните возможную потерю охвата и предложите сравнить результат.
Не включайте остальные категории молча ради этой рекомендации.

## Что означают категории

Имена в API не обозначают операторы соответствия ключевой фразы. В частности,
`Exact` — это **целевые**, а не узкие запросы и не буквальное совпадение строки.
Директ оценивает предложение по объявлению и посадочной странице.

| Категория и поле API | Смысл | Когда и зачем подключать |
|---|---|---|
| Узкие — `Narrow` | Запрос конкретнее предложения в объявлении, например уточняет модель или характеристики | Старт с небольшим бюджетом, специализированные товары и услуги: проверить более конкретный спрос |
| Целевые — `Exact` | Предложение непосредственно отвечает запросу | Первый кандидат на расширение, если узких мало: собрать основной спрос без требования максимальной конкретности |
| Широкие — `Broader` | Запрос шире конкретного предложения | Есть ассортимент или подходящая страница для общего спроса; нужен дополнительный объём и бюджет на проверку |
| Альтернативные — `Alternative` | Пользователь ищет другой способ решить ту же задачу | Продукт действительно заменяет искомое решение, а объявление объясняет замену; например, дальномер вместо измерительной рулетки |
| Сопутствующие — `Accessory` | Интерес к связанным товарам или услугам | Есть осмысленное дополнительное предложение: например, аксессуары покупателям основного устройства. Связь с темой сама по себе не означает намерения купить ваш товар |

Узкие — не обязательно редкие или дешёвые запросы. Они не отменяют проверку посадочной страницы, реальных запросов
и минус-фраз. В сомнительных случаях посмотрите примеры запросов категории
в интерфейсе Директа: не определяйте категорию только по числу слов.

## Бренды — отдельный выбор

`BrandOptions` управляет упоминаниями брендов независимо от пяти категорий:

- `WithoutBrands` — запросы без бренда рекламодателя и конкурентов.
- `WithAdvertiserBrand` — с брендом рекламодателя: уместны для работы с уже
  знакомой с компанией аудиторией; её результат оценивайте отдельно от нового спроса.
- `WithCompetitorsBrand` — с брендами конкурентов: это отдельная проверка спроса,
  если предложение может конкурировать с ними. Не включайте ради одного роста охвата.

«Только узкие» не означает «без брендов конкурентов». При изменении категорий
сохраните существующий выбор брендов, если пользователь не поручил менять его.
Для новой группы явно определите и покажите выбор брендов. Не считайте
пропущенную настройку выключенной: проверьте фактические значения после создания.

## Как оставить только узкие

Примеры запускаются из каталога скилла; логин и ID условные.
Сначала прочитайте группу: автотаргетинг мог уже появиться при её создании.

```bash
uv run scripts/keywords.py --account example --group 456 \
  --autotargeting --no-cache --json
```

Возьмите ID автотаргетинга из `keywords[].id`; исходное значение `Keyword` у
него — `---autotargeting`. Задайте **все пять** категорий. Здесь `789` — ID
автотаргетинга, а не группы или обычной фразы:

```bash
uv run scripts/keywords_write.py autotargeting set --account example --keyword 789 \
  --category Narrow=YES --category Exact=NO --category Broader=NO \
  --category Alternative=NO --category Accessory=NO
```

Без `--apply` команда показывает план; для порученной записи добавьте `--apply`.
Если объекта ещё нет, используйте `autotargeting add --group 456` с теми же пятью
`--category` и отдельно выбранными `--brand ИМЯ=YES|NO`.

Одного `Narrow=YES` недостаточно: `Keywords.update` сохраняет неназванные
категории, а `Keywords.add` включает пропущенные по умолчанию. Для правки
используется современная структура `AutotargetingSettings`; старая
`AutotargetingCategories` не выражает узкую категорию. При `set` без `--brand`
настройки брендов не передаются и сохраняются.

Покажите пользователю все пять значений «было → станет», после записи
перечитайте их и выбор брендов той же командой чтения. На Поиске и в Картах
должна остаться хотя бы одна категория; полностью отключить автотаргетинг
можно в кампаниях только с РСЯ. Ручная ставка — отдельная настройка;
выбор узких запросов её не меняет.

При переводе кампании из РСЯ на Поиск или Карты Директ включает все категории:
перечитайте их и задайте выбранный состав заново. Изменения могут применяться
к показам до суток; успешное чтение новых настроек подтверждает запись,
а фактический состав трафика проверяется позднее по отчётам.

## Как расширять и оценивать результат

Расширяйте охват под конкретную задачу: узких запросов недостаточно, есть
подходящий ассортимент или проверяется спрос на альтернативное решение.
Назовите добавляемую категорию, ожидаемый спрос, допустимый расход на проверку
и результат, который пользователь считает ценным. По возможности меняйте
по одной категории, чтобы понимать причину изменения трафика.

Проверяйте реальные поисковые запросы, расход, качество обращений и стоимость
конверсии по **выбранным пользователем целям**. Срезы «Категория запроса» и
«Упоминание брендов в запросах» доступны в интерфейсе Директа. Старое поле
Reports API `TargetingCategory` не выделяет `Narrow`; готовый `search_queries`
не даёт современной разбивки по всем пяти категориям. Не восстанавливайте
её по тексту запроса наугад. Выбор целей, атрибуция и сравнение периодов —
в [REPORTS.md](REPORTS.md), стартовые ограничения расхода — в [BUDGETS.md](BUDGETS.md).

Рост показов или дешёвые клики сами по себе не доказывают пользу расширения.
Если пошёл посторонний спрос, уточните предложение и минус-фразы либо отключите
неудачную категорию. Если данных мало, назовите неопределённость; не объявляйте
категорию плохой после одного клика или хорошей после одной конверсии.
