# Как подготовить комбинаторное объявление

Директ выбирает заголовок и текст из набора. Поэтому работа заканчивается, когда любая их пара понятно и достоверно описывает предложение. Число вариантов само по себе не показывает качество.

## Что подготовить

Сначала прочитайте фразы группы и страницу назначения. Определите, что человек ищет, какие особенности предложения важны и какие обещания подтверждены. Уточните неизвестные цену, срок, скидку или условия доставки; не придумывайте их для заполнения набора.

В комбинаторном объявлении до семи заголовков и трёх текстов. Каждый заголовок — законченная мысль, понятная и без основного текста: на части площадок текст может не показываться. Текст дополняет заголовок, но не должен зависеть от конкретного заголовка.

Хорошие варианты раскрывают разные подтверждённые свойства предложения: продукт, условия покупки, доставку, ассортимент, отличия. Несколько перестановок одной мысли не дают полезного выбора. Набор направлений выбирается по спросу группы; обязательного списка мотивов нет.

Методика требует показать бренд для узнаваемости. Сначала найдите ему место в заголовке, затем в основном тексте, а если он не помещается и туда — в отображаемой ссылке. Последний вариант может обрезаться и должен соответствовать содержанию предложения. Цена уместна, если она актуальна и пользователь хочет её показывать: она отсекает часть нецелевых кликов, но может уменьшить переходы.

Для кампании с достаточным спросом ориентир методики — полный набор до семи заголовков и трёх текстов; слабые повторы не заменяют разные полезные сообщения. Для бренда, премиального предложения, малого бюджета или сообщения, требующего контроля, предлагается меньший набор. При проверке существующей кампании различайте осознанный короткий набор и набор, оставшийся после автоматического перевода старого объявления в комбинаторное.

## Как проверить

1. Проверьте ограничения полей командой `check`.
2. Выведите все пары в `matrix` и прочитайте их целиком.
3. Исправьте повторы, противоречия, несогласованные окончания и части фраз, понятные только вместе.
4. Если используются шаблоны, повторите проверку для каждой ключевой фразы и запасного текста.
5. Покажите пользователю итоговые тексты и предпросмотр. При изменении существующего объявления покажите весь набор до и после.

Автоматическая проверка находит длины, точные повторы и формальные признаки; смысл, достоверность обещаний и уместность формулировок оценивает агент. Успешная запись в API не означает одобрения модерацией.

Из каталога скилла:

```bash
python3 scripts/ads_generate.py check --brief brief.json
python3 scripts/ads_generate.py matrix --brief brief.json --csv matrix.csv
python3 scripts/preview.py matrix --brief brief.json
```

Замечание можно привязать к паре (`3x1`), заголовку (`5`), комплекту целиком или паре с конкретной фразой:

```bash
python3 scripts/ads_generate.py check --brief brief.json   --mark "3x1:текст противоречит заголовку"   --mark "5:заголовок не понятен без текста"   --mark "1x1@пластиковые окна:не согласован падеж"
```

Генератор также умеет дополнять набор (`fill`) и собирать несколько наборов из CSV или JSON (`build`). Список аргументов доступен через `--help`.

## Несколько комплектов из таблицы

```csv
phrase,param1,group
профнастил оцинкованный,profile-1,кровля
профнастил С-8,profile-2,кровля
штакетник металлический,fence-1,забор
```

```bash
python3 scripts/ads_generate.py build   --data rows.csv --brief template.json --csv kits.csv
```

Комплект формируется по группе строк, подстановки проверяются по каждой строке. Значения `param1` и `param2` необходимо также установить фразам в кабинете: генератор их не записывает.

Одинаковые элементы разных объявлений могут объединиться в поэлементной выгрузке Мастера отчётов. Без однозначного соответствия нельзя приписывать такой строке результат отдельного объявления или конкретной пары. Статистика и ограничения измерения описаны в [REPORTS.md](REPORTS.md).

Запись выполняется через `ads_write.py`: свежее чтение, сравнение «было → станет», применение разрешённой задачи и перечитывание результата. Частичная правка должна сохранять весь остальной набор; особенности API описаны в [API_OBJECTS.md](API_OBJECTS.md).
