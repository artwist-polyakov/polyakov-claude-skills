# Макросы в ссылках

Директ подставляет значения `{…}` при переходе по объявлению. Для разметки используйте документированные параметры. Исходный поисковый запрос пользователя в URL не передаётся: его получают через Reports, поле `Query`.

## Доступные параметры

| Макрос | Что подставляет | Передаваемое значение |
|---|---|---|
| `{ad_id}`, `{banner_id}` | идентификатор объявления | число |
| `{campaign_name}` | название кампании | текст, до 255 символов |
| `{campaign_name_lat}` | транслитерированное название кампании | текст латиницей, до 255 символов |
| `{campaign_type}` | тип кампании | `type1` — ЕПК; `type2` — Продвижение приложений (тип больше не поддерживается); `type3` — Динамические объявления (тип больше не поддерживается); `type4` — Смарт-баннеры (тип больше не поддерживается); `type6` — Баннер на поиске |
| `{campaign_id}` | идентификатор кампании | число |
| `{creative_id}` | идентификатор креатива из конструктора | число |
| `{device_type}` | тип устройства, на котором произведён показ | `desktop`, `mobile`, `tablet` |
| `{gbid}` | идентификатор группы | число |
| `{keyword}` | ключевая фраза, по которой было показано объявление (текстово-графическое в ЕПК или Продвижение приложений) | текст ключевой фразы без минус-слов |
| `{phrase_id}` | идентификатор ключевой фразы для текстово-графических объявлений в ЕПК или продвижения приложений | число |
| `{retargeting_id}` | идентификатор условия нацеливания на аудиторию, связывающего группу объявлений с условиями ретаргетинга и подбора аудитории или интересами к мобильным приложениям | число |
| `{coef_goal_context_id}` | идентификатор корректировки ставок для условия ретаргетинга и подбора аудитории | число |
| `{match_type}` | тип соответствия условия показа и поискового запроса | `rm` — автотаргетинг; `syn` — семантическое соответствие |
| `{matched_keyword}` | подобранная фраза (справка велит использовать вместе с `{match_type}`) | текст подобранной фразы или семантического соответствия |
| `{adtarget_name}` | условие нацеливания; **параметр больше не поддерживается**, справка рекомендует удалить его из ссылок | название условия нацеливания |
| `{adtarget_id}` | идентификатор условия нацеливания | число |
| `{position}` | точная позиция объявления в блоке; по ней самой тип блока не определить, поэтому справка велит брать вместе с `{position_type}` | номер позиции в блоке; `0` — показ в сетях |
| `{position_type}` | тип блока, если показ произошёл на странице результатов поиска Яндекса | `premium`, `dynamic_places`, `other`; `none` — показ в сетях |
| `{source}` | место показа | домен площадки — при показе в сетях; `none` — при показе на поиске Яндекса |
| `{source_type}` | тип площадки, на которой произведён показ | `search`, `context` |
| `{region_name}` | регион, в котором было показано объявление | название региона |
| `{region_id}` | идентификатор региона | число |
| `{yclid}` | идентификатор клика по объявлению Директа | число |

## Как понимать значения

`{keyword}` — заданная ключевая фраза без минус-слов. `{matched_keyword}` — фраза, подобранная Директом, а `{match_type}` поясняет подбор: `rm` — автотаргетинг, `syn` — семантическое соответствие. Пустое значение само по себе не доказывает поломку: нужного объекта или подбора могло не быть в данном показе.

`{position}` нужно читать вместе с `{position_type}`: номер позиции без типа блока не показывает, была ли реклама в верхнем блоке. Для сетей значения — `0` и `none`; `{source}` обычно содержит домен площадки. На поиске Яндекса `{source}` равен `none`; на поисковых площадках РСЯ возможны оба варианта.

Имени группы, текста объявления и реального поискового запроса среди макросов нет. Названия объектов уточняются через API по идентификаторам, запросы — отчётом за доступный период, до 180 дней. Настройка разметки не заменяет этот отчёт.

## Ограничения

- `{adtarget_name}` больше не поддерживается: удалите его при согласованном обновлении схемы.
- Кириллица увеличивает длину URL после кодирования. При превышении 4096 байт документация гарантирует передачу только `yclid` и openstat; не рассчитывайте на остальные макросы в слишком длинной ссылке.
- В быстрых ссылках подстановка `{campaign_id}`, `{ad_id}`, `{banner_id}` и `{phrase_id}` гарантируется при наличии тех же параметров в основной ссылке объявления.
- Значение `utm_source` с подстрокой `yandex` может сокращаться до `ya`. Для новой схемы предлагается `ya`; изменение существующей схемы учитывает настройки аналитики.
- Макросы аудитории, креатива и соответствия полезны только там, где такой объект участвует в показе. Не объявляйте весь набор проверенным по одному переходу.
