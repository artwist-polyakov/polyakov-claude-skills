# Где искать настройки в интерфейсе Директа

Используйте эту карту, когда действие выполняется в кабинете или пользователь хочет найти настройку сам. Названия экранов могут меняться. Сначала убедитесь, что открыт нужный рекламодатель и кампания, затем дайте путь и конкретные значения.

Готовые адреса экранов и подстановка логина или идентификатора: [ui_deeplinks.json](ui_deeplinks.json). Доступность операций через API: [coverage.json](coverage.json). Ссылка на экран не означает, что настройка уже изменена.

## Ссылки на кабинет и кампанию

Ссылка на кампанию собирается из логина рекламного кабинета (`ulogin`) и
числового ID кампании (`campaigns-ids`). Имя кампании и имя группы в URL не
используются. Для агентского доступа указывай логин клиента, которому принадлежит
кампания, а не владельца токена. Для нескольких кабинетов у каждой строки свой
логин.

| Куда перейти | Формат ссылки |
|---|---|
| Группы выбранной кампании | `https://direct.yandex.ru/dna/grid/groups?ulogin=LOGIN&campaigns-ids=ID` |
| Настройки выбранной кампании | `https://direct.yandex.ru/dna/campaigns-edit?ulogin=LOGIN&campaigns-ids=ID` |
| Кампании кабинета | `https://direct.yandex.ru/dna/grid/campaigns?ulogin=LOGIN&filter-reset=true&stat-preset=last30Days&dim-filter=CPC_AND_CPM&status-filter=ALL_EXCEPT_ARCHIVED` |

В анализе и списке рекомендаций название кампании делай ссылкой на её группы.
Для проверки или изменения настроек давай «Настройки». После создания можно
дать пару «Открыть кампанию · Настройки». При обсуждении кабинета целиком
используй ссылку на список его кампаний. Если ID ещё неизвестен, дай ссылку
на кабинет; у ещё не созданной кампании своей ссылки нет.

Ссылка на кабинет открывает последние 30 дней, показывает кампании с оплатой за
клики и показы, скрывает архивные. Это только параметры открываемого экрана:
они не меняют период выполненного анализа и настройки рекламы. Для поиска
архивной кампании измени фильтр в интерфейсе или используй её прямую ссылку.

`accounts.py` выдаёт `account_url`, `campaigns.py` — `account_url`, `url` и
`edit_url`; `campaign_write.py` — `account_url` и список `campaign_links` с
`id`, `url`, `edit_url`. При создании ссылка появляется после получения ID
от API; наличие ссылки само по себе не подтверждает успех всех изменений.

Для других команд и ответов используй те же форматы. В коде общий способ —
`account_url(login)` и `campaign_url(login, campaign_id, edit=False)` из
`scripts/lib/ui_links.py`; он кодирует параметры URL и не обращается к API.
Не добавляй в ссылки токены и данные сессии. Для открытия пользователь должен
быть авторизован в Яндексе и иметь доступ к выбранному кабинету.

## Как передать действие пользователю

Назовите объект, путь к настройке и сравнение «было → станет». Если полезно, откройте нужную страницу. После ручного изменения предложите проверить результат доступным чтением API; если поле API не возвращается, это следует прямо назвать.

Для статистики сначала выбираются ценные цели; порядок анализа описан в [REPORTS.md](REPORTS.md). Для правки текстов и других значений сравнение и проверка результата описаны в [CHANGES.md](CHANGES.md).

## 7. Таргетинги и условия показа

| Инструмент | Где | Суть |
|---|---|---|
| **Ключевые фразы** | группа → **Тематические слова** | до 200 на группу, до 7 слов и 4096 символов на фразу |
| **Минус-слова** | у ключевой фразы через `-` | сужают конкретную фразу |
| **Минус-фразы** | группа (4096 симв.) и кампания (20 000 симв.) | суммируются с минус-словами, не заменяют их |
| **Операторы** | `" "`, `[ ]`, `!`, `+`, `-` | фиксация формы, порядка, стоп-слов |
| **Автотаргетинг** | группа | категории запросов + упоминание брендов; на Поиске и в Картах обязателен |
| **Интересы и привычки** | группа | профиль пользователя для сетей |
| **Сегменты аудитории** | группа → **Сегменты аудитории**; создаются в **Библиотека → Сегменты аудитории** | цели и сегменты Метрики, сегменты Аудиторий; на Поиске работают через «И» с фразами, в сетях — через «ИЛИ» |
| **Офферный ретаргетинг** | группа, для товарных объявлений и каталогов | возврат к просмотренным предложениям в РСЯ |
| **Сценарий группы** | группа | «Новая аудитория» / «Новые покупатели» исключают текущих клиентов |
| **География показов** | группа | дерево регионов или точки на карте |
| **Расширенный геотаргетинг** — убран | экрана нет | Убран из кампаний обновлением геотаргетинга (, 01.09.2026): показы по запросам с названием региона и по регулярному региону Директ теперь ведёт сам, отдельного переключателя под них не осталось |
| **Временной таргетинг** | кампания → **Расписание показов** | дни, часы, праздники, рабочие выходные |
| **Приостановка показов по фразе** | страница кампании, блок редактирования фраз | статистика по фразе сохраняется |

| Корректировка | Уровень | Комментарий |

## Модерация

Причину отклонения ищите у объявления и отдельных элементов, затем сопоставьте её с текстом и страницей перехода. При правке может продолжать показываться предыдущая версия; смотрите состояние показов отдельно от статуса модерации. Если решение кажется ошибочным, используйте обращение в поддержку из кабинета и приложите идентификаторы и конкретное объяснение.

Для тематик с особыми условиями документы отправляются через предусмотренную форму. Проверка длины текста и успешная запись API не заменяют модерацию. Подробности: [AD_CONTENT.md](AD_CONTENT.md).

## Оплата и доступы

В общем счёте находятся баланс, пополнение, счета и платёжные документы; настройки могут включать автоплатёж, бюджет аккаунта, отсрочку, бонусы и возврат. Финансовые операции выполняет пользователь в кабинете. Не передавайте платёжные документы или данные кабинета третьим лицам без его поручения.

Доступ представителей и управляющих аккаунтов настраивается отдельно от токена приложения. У агентства сначала выбирается клиент; сведения об агентстве не означают, что открыт рекламодатель.

Мастер кампаний, отдельные медийные и товарные настройки, промоакции, часть инструментов и обращения по модерации могут требовать интерфейса даже при доступном API. Отсутствие команды означает, что пользователю нужен точный путь, а не предположение об успехе.
