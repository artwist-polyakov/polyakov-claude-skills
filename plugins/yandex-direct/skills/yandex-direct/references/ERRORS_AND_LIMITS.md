# Ошибки, ограничения и баллы

Используйте этот файл при конкретной ошибке или подготовке запроса. Локальные числа и размеры пакетов берутся из [limits.json](limits.json); ограничения кабинета и валюты уточняются через `Clients.get` и `Dictionaries.get`. Не меняйте число наугад, если API сообщает иной предел.

## Порядок действий при ошибке

1. Прочитайте код, понятное сообщение и идентификатор запроса. Не выводите токен и заголовок авторизации.
2. Определите уровень: весь вызов или отдельные объекты внутри успешного HTTP-ответа.
3. Покажите, что уже применилось, что не применилось и что осталось неизвестным.
4. Временно неудавшееся чтение можно повторить с задержкой. Запись с неизвестным исходом сначала проверяется чтением: повтор может создать дубли.

HTTP 200 не гарантирует успех. При чтении `LimitedBy` означает следующую страницу; отсутствие запрошенного объекта и неполная выборка — разные ситуации.

Деньги в JSON API обычно выражены миллионными долями валюты кабинета. Денежный формат Reports определяется параметрами запроса. Не смешивайте эти значения и явно называйте валюту, НДС и выбранную модель атрибуции в отчёте.

## 2. Что ломается чаще всего

| Симптом | Причина | Раздел |
|---|---|---|
| `error_code 54` на `AgencyClients.get` | токен не агентский, это штатный ответ | [9.5](#95-код-54--не-всегда-ошибка) |
| HTTP 200, а объекты не создались | ошибки лежат внутри элементов результата | [9.2](#82-http-200-ничего-не-означает) |
| В ответе меньше объектов, чем в кабинете | сработал лимит выборки, вернулся `LimitedBy` | [4.2](#42-постраничная-выборка) |
| После обновления объявления остался один заголовок | `update` требует полного комплекта | [API_OBJECTS.md](API_OBJECTS.md), раздел о `ResponsiveAd` |
| Бюджет отличается в миллион раз | забыт множитель | [5](#5-деньги) |
| `error_code 506` | больше пяти одновременных запросов | [4.4](#44-параллелизм) |
| `error_code 152` | кончились баллы, ждать начисления | [6.5](#65-что-делать-при-исчерпании) |
| `error_code 53` на методе версии 4 при исправном токене | токен ушёл заголовком, а четвёртая версия берёт его из тела | [7](#7-заголовки) |

### 3.5. Медиа

| Правило | Соотношение сторон | Размер |
|---|---|---|
| Квадрат и близкие | от 3:4 до 4:3, то есть от 0,75 до 1,3333 | обе стороны от 450 до 5000 пикселей |
| Широкое | 16:9 с допуском ±0,005, то есть от 1,7728 до 1,7828 | от 1080 × 607 до 5000 × 2812 |

| Правило | Край | Принято | Отвергнуто |
|---|---|---|---|
| стороны 450…5000 | нижний | 450 × 450 → `REGULAR` | 449 × 449 → `5004` |
| ^ | верхний | 5000 × 5000 → `REGULAR` | 5001 × 5001 → `5004` |
| 16:9 от 1080 × 607 | нижний | 1080 × 607 → `WIDE` | 1079 × 607 → `5004` |
| ^ | верхний | 5000 × 2812 → `WIDE` | не пробовался |

## Практические замечания

Узкие символы `!,.;:"` могут считаться отдельно от обычных символов текста объявления. Решётки шаблона не входят в его длину; обычная решётка фрагмента URL входит. Для правильного расчёта используйте штатную проверку, а не простое обрезание строки.

Ошибка `54` от `AgencyClients.get` может означать, что токен принадлежит прямому рекламодателю. Проверьте через `Clients.get`; не объявляйте токен испорченным по одному этому ответу. Ошибка `58` означает незавершённый доступ приложения: [API_ACCESS.md](API_ACCESS.md).

При нехватке баллов остановите требующие их операции и назовите причину. Агентский доступ может использовать баллы агентства по поддержанному механизму; это не повод менять выбранный кабинет. Остаток v4 и v5 не смешивается.

Если пакет применился частично, продолжайте только с установленным результатом по каждому объекту. Полного автоматического отката нескольких успешных API-запросов Директ не обещает. Журнал прежних значений помогает восстановить поля, но не возвращает удалённому объекту его историю.

Источники: [ограничения API](https://yandex.ru/dev/direct/doc/ru/concepts/restrictions), [справочник API](https://yandex.ru/dev/direct/doc/ru/).
