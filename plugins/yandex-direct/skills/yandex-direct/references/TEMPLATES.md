# Шаблоны и параметры фраз

У объявления есть три разных механизма подстановки:

| Механизм | Пример | Откуда значение |
|---|---|---|
| Шаблон фразы | `Купить #окна# в Москве` | Ключевая фраза показа; «окна» — запасной текст |
| Параметр фразы | `{param1}`, `{param2}` | `Keyword.UserParam1` и `UserParam2` |
| Макрос Директа | `{keyword}`, `{campaign_id}` | Директ подставляет при показе |

## Шаблон #…#

Текст между решётками обязателен: он сохраняет смысл, если подстановка не помещается. Решётки образуют пары слева направо; вложенности нет. Регистр и грамматическое согласование автоматически не исправляются.

Шаблоны поддерживаются в заголовках, текстах, основной и отображаемой ссылке. В заголовках быстрых ссылок `#окна#` останется буквальным текстом. Обычный фрагмент URL после `#` также не является шаблоном.

Проверяйте каждую подстановку по всем фразам группы, включая запасной текст. Один принятый API заголовок не подтверждает, что остальные варианты помещаются или правильно читаются. В комбинаторном объявлении нужна проверка каждой пары заголовка и текста по каждой фразе.

Пример:

```text
Купить #окна# в Москве
```

Для «пластиковые окна» получится «Купить пластиковые окна в Москве». Если слишком длинная фраза не помещается, Директ использует «Купить окна в Москве». Решётки шаблона не учитываются в длине; обычная решётка фрагмента URL учитывается.

Локальный расчёт очищает ключевую фразу от операторов и минус-слов. Это модель подстановки; фактический переход остаётся способом проверить конкретный адрес. Ограничения полей берутся из [limits.json](limits.json).

## Параметры param1 и param2

Значения принадлежат ключевой фразе, а не объявлению. Они используются в основной ссылке, например `https://example.ru/catalog/{param1}/`. Для каждой фразы нужно установить собственное значение, до 255 символов. Пустой параметр оставляет пустое место: адрес может стать `https://example.ru/catalog//` и вести не туда.

Параметры читаются через `Keywords.get`, задаются командами `keywords_write.py keyword param --param1` или `keyword add --param1`. Очистка явно задаётся `--clear param1` или `--clear param2`: пропуск поля означает «не менять», а `null` — убрать значение.

Значение в CSV для генератора само по себе не записывается фразе в кабинете. Установите его отдельной командой до использования объявления. Параметры, записанные автотаргетингу, не дают обычной фразы для расчёта подстановки.

## Проверка ссылки

- Пробел и специальные символы подставляемого значения кодируются; сайт должен принимать итоговый адрес.
- `Href` ограничен 1024 символами. Для итогового URL есть отдельная граница 4096 байт, после которой нельзя рассчитывать на передачу всех динамических параметров.
- Новые параметры помещаются перед фрагментом после `#`. Адрес, одновременно содержащий шаблон и фрагмент, проверьте отдельно: назначение решёток должно быть однозначным.
- Отображаемая ссылка ограничена 20 символами и собственным набором допустимых знаков. Подстановка фразы с пробелами может нарушить эти ограничения.
- UTM-разметку не дублируют в ссылке и `TrackingParams`.

Пример сочетания механизмов:

```text
https://example.ru/catalog/{param1}/?q=#okna#&utm_term={keyword}
```

Здесь `{param1}` — значение фразы, `#okna#` — шаблон с запасным текстом, `{keyword}` — макрос Директа. `{utm_term}` макросом не является: `utm_term` — имя параметра URL.

## Команды

Из каталога скилла:

```bash
python3 scripts/ads_generate.py check --brief brief.json
python3 scripts/ads_generate.py matrix --brief brief.json --csv matrix.csv
python3 scripts/ads_generate.py build --data rows.csv --brief template.json --csv kits.csv
```

Для комплектов с `#…#`, `{param1}` или `{param2}` нужны фразы и значения параметров. Обычные макросы Директа не требуют заранее известных значений фраз. Генератор готовит и проверяет данные; в кабинет записывает `ads_write.py`.

Справка: [макросы URL](url_macros.md), [разметка](naming.md), [комбинаторные объявления](COMBINATORIAL_COPY.md).
